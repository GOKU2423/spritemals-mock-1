# SPRITEMALS — Mock 1

## Goal
Build a polished, mobile-first prototype that makes the complete business loop immediately clear: real pet → custom Spritemal → virtual AI companion → physical plush and matching merchandise.

## Experience
- Create a dark cosmic collectible-creature interface with neon energy, glass surfaces, portal platforms, and premium game-like presentation.
- Open with SPRITEMALS, “Welcome to Spritemals,” “A Goku24 Product,” and a strong “Create My Spritemal” action.
- Present KING, JADE, and DUKE as selectable AI Spritemal assistants, with JADE featured by default and each character’s specified personality.
- Build a clickable five-step creation studio: upload/camera, simulated generation, visual customization, naming/saving, and product selection.
- Add “My Spritemals” and a virtual companion room with playful interactions that make the saved creature feel like a digital plushie.
- Build a merchandise shop where the custom plush is the hero, supported by bowls, collars, leashes, stickers, art, blankets, clothing, and keychains. All prices remain exactly “$—” and ordering is clearly presented as a prototype.
- Provide mobile bottom navigation and a desktop navigation treatment, with responsive layouts throughout.

## Visual assets
Generate original placeholder artwork for the three named guides and a customizable pet companion. Keep artwork in replaceable image slots so approved character and logo files can be swapped in later without redesign.

## Technical details
- Keep the prototype entirely local and front-end only; no paid services, checkout, account system, or production AI integration.
- Use React state to drive assistant selection, creation stages, customization, saving, product actions, and companion interactions.
- Define all visual colors, shadows, and effects as semantic design tokens in the global design system.
- Add app-specific metadata and verify the central flow at mobile and desktop sizes.

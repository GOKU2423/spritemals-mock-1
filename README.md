# Spritemals Companion Studio

Build SPRITEMALS — Mock 1, a polished mobile-first app-style prototype for an original AI pet-companion and merchandise brand. Make it feel like a premium collectible-creature universe, not a generic pet store.

Brand:
- Exact name: SPRITEMALS.
- Attribution: “A Goku24 Product.”
- Visual direction: dark cosmic/night backdrop, neon cyan/blue/purple energy, glassy cards, glowing portals/platforms, playful premium 3D-game feeling.
- Primary mascot/guide: JADE, a gray/white blue-eyed dire wolf.
- Other companions: KING, a golden lion with regal/crown energy; DUKE, a friendly black-and-tan Rottweiler.
- Never use “Animal Sprites” as current branding. Character names must always be exactly KING, JADE, DUKE.

Core opening experience:
Show SPRITEMALS branding and “Welcome to Spritemals” with a strong CTA to “Create My Spritemal.” Introduce the three guides as selectable companions. JADE should be featured by default. Each guide should have a distinct short personality: KING confident/protective/adventurous; JADE clever/wild/slightly mischievous; DUKE loyal/friendly/funny. Clearly label them as AI Spritemal assistants in prototype UI.

Core creation flow must feel interactive:
1. Upload Your Pet
2. Create a Spritemal
3. Customize It
4. Name & Save It
5. Choose Products
For Mock 1, simulate generation/customization convincingly without requiring a production AI backend. Include an upload drop zone/camera-style control, generation animation/state, and customization controls for things like collar color, markings, eyes, accessory/theme, and name. Include a saved “My Spritemals” area and a virtual-companion screen that makes the created animal feel like a digital plushie/companion.

Shop:
Plushies are the hero product and should receive the strongest merchandising treatment, including “Bring Your Spritemal Home” / custom physical plush concept. Also include pet bowls, collars, leashes, stickers, posters/framed art, blankets, clothing, and keychains. Every price must be exactly “$—” as a placeholder. Product cards can be functional prototype interactions with customize/add buttons, but do not pretend checkout or manufacturing is live.

Navigation:
Mobile-first bottom navigation such as Home, Create, My Spritemals, Shop, Companion. Make it responsive so it also looks excellent on desktop.

Important product concept:
The core loop is Real Pet → Spritemal → Virtual Plushie/AI Companion → Physical Plushie & matching merchandise. Make this idea immediately understandable through the interface. The app should be exciting enough that someone can see the business concept without explanation.

Use tasteful placeholder creature artwork/graphic treatments if the exact approved character PNG assets are not available in the project yet; structure the design so the approved KING, JADE, DUKE and SPRITEMALS logo images can be dropped in afterward without redesigning the layout. Do not use Fortnite logos, Fortnite UI, or imply affiliation with another game.

This is MOCK 1: prioritize a complete, clickable, visually impressive prototype and coherent customer journey over production integrations. Do not add paid services, paid checkout, or anything that requires a subscription just to preview the prototype.
